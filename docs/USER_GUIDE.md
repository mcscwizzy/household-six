# User guide

1. Open the local HTTPS site and create the household owner on the first-run screen.
2. Sign in with the local username and password. The account does not use an outside identity provider.
3. Use the bottom navigation for Today, Calendar, Tasks, Meals and More. Tap **+** or **Add** to save an event, task, meal, shopping entry, recipe, inventory item, reward, or announcement.
4. An owner or admin can add member profiles under More → Members. Child profiles do not need an email. An adult profile needs a password to sign in.
5. Mark a task or list entry complete with its check button. A task with points assigned to a member adds those points exactly once.
6. More → Settings changes appearance or password. Signing out removes cached profile/list data and pending offline completions for that browser profile.

The calendar, recipes, inventory and rewards are simple shared records in this alpha; they do not yet provide the advanced workflows listed in the full project request.
